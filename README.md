# CS405G---Fundamentals-of-Programming-Languages

Coursework and implementations exploring programming language principles, formal syntax, semantics, and type systems. 

### Covered Paradigms & Languages
- **OCaml:** Functional programming, algebraic data types, pattern matching, closures, and type inference.
- **TypeScript:** Structural type systems, flow-sensitive type inference, and programming in the large.
- **Dafny:** Program verification, pre/post-conditions, and loop invariants.
- **Bosque:** Zero-mutation design and tooling/AI-centric paradigms.
